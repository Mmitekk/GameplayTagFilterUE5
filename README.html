GameplayTag Filter (Unreal Engine)

Blueprint-ноды / Blueprint nodes · UE 5.2 & 5.8 · Win64

Пять Blueprint-нод, которые достают акторы с нужным Gameplay Tag из массива или мапы одной нодой — вместо связки ForEach → Actor Has Tag → Branch → Add.

Совместимость

  • Unreal Engine 5.2 и 5.8 (Win64), исходники без версионной специфики
  • Один Runtime-модуль, GAS (AbilitySystemComponent) не нужен — стандартные Actor Tags (FName)

Установка

Скопируйте папку GameplayTagFilter в <Проект>/Plugins/ и перезапустите редактор. Ноды появятся в палитре в категории Tag Filter.

Ноды

НодаВходВыход
Filter Actors by Tagмассив акторов + один тегсовпавшие акторы + MatchCount
Filter Actors by Tagsмассив акторов + контейнер тегов + режим Any/Allсовпавшие акторы + MatchCount
Find Actors in Tag MapTMap<FGameplayTag, AActor*> + тег (сравниваются ключи)акторы + совпавшие ключи + MatchCount
Find Actors in Tag Groupsмассив FTaggedActorArray {Tag, Actors[]} + тегакторы всех подошедших групп + их теги + MatchCount
Filter Actors Map by TagTMap<AActor*, FGameplayTagContainer> + тег (сравниваются теги-значения)акторы, чьи теги совпали + MatchCount

Все ноды BlueprintPure — без exec-пинов.

Сравнение тегов (пин bExactMatch)

  • false (по умолчанию) — иерархия, как в GAS: запрос Damage находит Damage и Damage.Fire, но не родителя.
  • true — только точное совпадение имени.
  • В мапе Тег → Актoр поиск идёт по ключу: запрос Damage вытащит и запись с ключом Damage.Fire.
  • Иерархия работает для тегов из словаря проекта (Project Settings → Gameplay Tags); незарегистрированные имена матчатся только точно.

Пример

Массив акторов:  Костёр [Damage.Fire]   Лук [Damage]   Дверь [Door]

Filter Actors by Tag (запрос: Damage, bExactMatch = false)
   → Костёр, Лук          (MatchCount = 2)

Filter Actors by Tag (запрос: Damage, bExactMatch = true)
   → Лук                  (MatchCount = 1)

Почему «тег → массив акторов» — это массив структур

Blueprint запрещает TMap<FGameplayTag, TArray<AActor*>> (вложенные контейнеры в мапах запрещены движком), поэтому вариант «тег → группа акторов» реализован нодой Find Actors in Tag Groups, принимающей массив структуры FTaggedActorArray (Tag + Actors) — семантика та же.

Сборка из исходников

"<Engine>\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin
  "-Plugin=<Path>\GameplayTagFilter.uplugin" "-Package=<OutDir>"
  -TargetPlatforms=Win64 -NoSubmit

Либо как часть проекта: скопировать плагин в <Проект>/Plugins/ и собрать таргет проекта.

Примечание: в UE 5.x модуль должен содержать явный IMPLEMENT_MODULE(FDefaultModuleImpl, GameplayTagFilter); — UHT не всегда генерирует обвязку сам (уже учтено в исходниках).

Five Blueprint nodes that fetch actors with a given Gameplay Tag from an array or a map in a single node — instead of wiring ForEach → Actor Has Tag → Branch → Add.

Compatibility

  • Unreal Engine 5.2 and 5.8 (Win64); source has no version-specific code
  • Single Runtime module, GAS (AbilitySystemComponent) not required — standard Actor Tags (FName)

Installation

Copy the GameplayTagFilter folder into <Project>/Plugins/ and restart the editor. The nodes appear in the palette under the Tag Filter category.

Nodes

NodeInputOutput
Filter Actors by Tagactor array + one tagmatching actors + MatchCount
Filter Actors by Tagsactor array + tag container + Any/All modematching actors + MatchCount
Find Actors in Tag MapTMap<FGameplayTag, AActor*> + tag (compares keys)actors + matched keys + MatchCount
Find Actors in Tag Groupsarray of FTaggedActorArray {Tag, Actors[]} + tagactors from all matching groups + their tags + MatchCount
Filter Actors Map by TagTMap<AActor*, FGameplayTagContainer> + tag (compares tag values)actors whose tags matched + MatchCount

All nodes are BlueprintPure — no exec pins.

Tag matching (the bExactMatch pin)

  • false (default) — hierarchical matching, same as GAS: the query Damage finds Damage and Damage.Fire, but not the parent.
  • true — exact name match only.
  • For the Tag → Actor map the lookup runs on keys: the query Damage also returns the entry keyed Damage.Fire.
  • Hierarchy only applies to tags registered in the project's tag dictionary (Project Settings → Gameplay Tags); unregistered names match exactly only.

Example

Actor array:   Campfire [Damage.Fire]   Bow [Damage]   Door [Door]

Filter Actors by Tag (query: Damage, bExactMatch = false)
   → Campfire, Bow        (MatchCount = 2)

Filter Actors by Tag (query: Damage, bExactMatch = true)
   → Bow                  (MatchCount = 1)

Why "tag → actor array" is an array of structs

Blueprint does not allow TMap<FGameplayTag, TArray<AActor*>> (nested containers are forbidden in maps), so the "tag → actor group" case is exposed as Find Actors in Tag Groups, taking an array of the FTaggedActorArray struct (Tag + Actors) — same semantics.

Building from source

"<Engine>\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin
  "-Plugin=<Path>\GameplayTagFilter.uplugin" "-Package=<OutDir>"
  -TargetPlatforms=Win64 -NoSubmit

Or as part of a project: copy the plugin into <Project>/Plugins/ and build the project target.

Note: in UE 5.x the module must contain an explicit IMPLEMENT_MODULE(FDefaultModuleImpl, GameplayTagFilter); — UHT does not always generate the boilerplate (already handled in this source).

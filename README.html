GameplayTag Filter (Unreal Engine)

Blueprint-ноды / Blueprint nodes · UE 5.2 & 5.8 · Win64

Пять Blueprint-нод, которые достают акторы с нужным Gameplay Tag из массива или мапы одной нодой — вместо связки ForEach → Actor Has Tag → Branch → Add.

Совместимость

  • Unreal Engine 5.2 и 5.8 (Win64), исходники без версионной специфики
  • Один Runtime-модуль; используются стандартные Actor Tags (список FName на панели актора), никаких дополнительных систем не нужно

Сначала о главном: что такое MatchCount

MatchCount — это просто число «сколько нашёл», всегда равное длине выходного массива. Он дублирует OutActors.Num(), чтобы не тянуть лишний узел: одно сравнение MatchCount > 0 отвечает на вопрос «нашёлся ли хоть кто-то». А Gameplay Tag Container — это просто список тегов (набор).

1. Filter Actors by Tag

«У меня есть массив акторов — оставить только тех, у кого есть тег X».

ПинЧто это
ActorsМассив акторов, которые проверяем
TagТег, который ищем
bExactMatchfalse (по умолчанию) — с иерархией: запрос Damage найдёт и Damage, и Damage.Fire. true — только точное имя
OutActorsРезультат: акторы, у которых тег нашёлся (в том же порядке, что на входе)
MatchCountСколько нашли. Равно длине OutActors — для быстрой проверки «нашёлся ли хоть один»

2. Filter Actors by Tags

То же самое, но ищем по нескольким тегам сразу.

ПинЧто это
ActorsМассив акторов, которые проверяем
TagsСписок тегов, которые ищем (Gameplay Tag Container)
MatchTypeAny — актору достаточно хотя бы одного тега из списка. All — нужны все теги из списка
bExactMatchКак в первой ноде
OutActorsАкторы, прошедшие фильтр
MatchCountСколько нашли

3. Find Actors in Tag Map

«У меня мапа, где ключ — тег, а значение — актор. Достать записи по тегу».

ПинЧто это
ActorMapСама мапа Тег → Актoр. У каждой записи: ключ — тег, значение — актор
TagТег-запрос. Сравнивается с ключами записей
bExactMatchfalse — запрос Damage находит и запись с ключом Damage.Fire; true — только точный ключ
OutActorsАкторы из всех записей, где ключ совпал
OutMatchedKeysКакие именно ключи совпали. Полезно при иерархическом поиске: запросили Status.ChangeFreeze, а совпал ключ Status.ChangeFreeze.Grill — здесь видно, какая ветка сработала
MatchCountСколько записей совпало (равно длине OutActors)

4. Find Actors in Tag Groups

«Тег → несколько акторов». Мапа с массивом внутри в Blueprint запрещена движком (вложенные контейнеры), поэтому такие данные хранятся как массив структур FTaggedActorArray — у структуры два поля: Tag (тег группы) и Actors (акторы группы). Нода возвращает сразу всех акторов подошедших групп.

ПинЧто это
GroupsМассив групп. Каждая группа = один тег + акторы, к нему относящиеся
TagТег-запрос. Сравнивается с тегом каждой группы
bExactMatchfalse — запрос Damage найдёт и группу с тегом Damage.Fire; true — только точное имя
OutActorsВсе акторы из всех подошедших групп, слитые в один массив
OutMatchedTagsТеги именно тех групп, что совпали (каждый — один раз)
MatchCountСколько акторов вернули. Может быть больше числа совпавших групп — в группе обычно несколько акторов

5. Filter Actors Map by Tag

«Мапа, где ключ — актор, а значение — список его тегов. Отобрать акторов по тегу».

ПинЧто это
ActorMapСама мапа Актoр → Теги
TagТег-запрос. Проверяется по списку тегов (значению) каждой записи
bExactMatchКак обычно: false — с иерархией, true — точно
OutActorsАкторы-ключи, в списке тегов которых нашёлся запрос
MatchCountСколько нашли

Общие правила сравнения

  • Записи с пустыми/битыми акторами молча пропускаются; пустой тег-запрос → пустой результат.
  • Иерархия работает только для тегов, зарегистрированных в словаре проекта (Project Settings → Gameplay Tags). Самодельные имена вне словаря совпадают только точно.
  • Направление иерархии всегда «от родителя к потомкам»: запрос-родитель находит потомков, но не наоборот.

Пример

Массив акторов:  Костёр [Damage.Fire]   Лук [Damage]   Дверь [Door]

Filter Actors by Tag (запрос: Damage, bExactMatch = false)
   → Костёр, Лук          (MatchCount = 2)

Filter Actors by Tag (запрос: Damage, bExactMatch = true)
   → Лук                  (MatchCount = 1)

Установка

Скопируйте папку GameplayTagFilter в <Проект>/Plugins/ и перезапустите редактор. Ноды появятся в палитре в категории Tag Filter.

Сборка из исходников

"<Engine>\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin
  "-Plugin=<Path>\GameplayTagFilter.uplugin" "-Package=<OutDir>"
  -TargetPlatforms=Win64 -NoSubmit

Либо как часть проекта: скопировать плагин в <Проект>/Plugins/ и собрать таргет проекта.

Примечание: в UE 5.x модуль должен содержать явный IMPLEMENT_MODULE(FDefaultModuleImpl, GameplayTagFilter); — UHT не всегда генерирует обвязку сам (уже учтено в исходниках).

Five Blueprint nodes that fetch actors with a given Gameplay Tag from an array or a map in a single node — instead of wiring ForEach → Actor Has Tag → Branch → Add.

Compatibility

  • Unreal Engine 5.2 and 5.8 (Win64); source has no version-specific code
  • Single Runtime module; works with standard Actor Tags (the FName list on the actor's panel), no extra systems required

First things first: what is MatchCount

MatchCount is simply "how many were found" — it always equals the length of the output array. It duplicates OutActors.Num() so you don't have to: one MatchCount > 0 comparison answers "did we find anything". And a Gameplay Tag Container is just a list of tags (a set).

1. Filter Actors by Tag

"I have an array of actors — keep only those that have tag X."

PinMeaning
ActorsThe actors to check
TagThe tag to search for
bExactMatchfalse (default) — hierarchical: query Damage finds both Damage and Damage.Fire. true — exact name only
OutActorsThe result: actors whose tags matched (input order preserved)
MatchCountHow many were found. Equals the OutActors length — handy for a quick "found anything?" check

2. Filter Actors by Tags

The same, but searching by several tags at once.

PinMeaning
ActorsThe actors to check
TagsThe list of tags to search for (a Gameplay Tag Container)
MatchTypeAny — one tag from the list is enough. All — every tag from the list is required
bExactMatchSame as the first node
OutActorsActors that passed the filter
MatchCountHow many were found

3. Find Actors in Tag Map

"I have a map where the key is a tag and the value is an actor. Fetch entries by tag."

PinMeaning
ActorMapThe Tag → Actor map itself. Each entry: key = tag, value = actor
TagThe query tag. Compared against the entry keys
bExactMatchfalse — query Damage also finds the entry keyed Damage.Fire; true — exact key only
OutActorsActors from all entries whose key matched
OutMatchedKeysWhich keys matched. Useful with hierarchical search: you queried Status.ChangeFreeze and the key Status.ChangeFreeze.Grill matched — here you see which branch responded
MatchCountHow many entries matched (equals the OutActors length)

4. Find Actors in Tag Groups

"A tag → several actors". A map with an array inside is forbidden in Blueprint (no nested containers), so such data is stored as an array of structs FTaggedActorArray — the struct has two fields: Tag (the group's tag) and Actors (the group's actors). The node returns all actors from all matching groups at once.

PinMeaning
GroupsThe array of groups. Each group = one tag + the actors belonging to it
TagThe query tag. Compared against each group's tag
bExactMatchfalse — query Damage also finds a group tagged Damage.Fire; true — exact name only
OutActorsAll actors from all matching groups, merged into one array
OutMatchedTagsThe tags of the groups that matched (each listed once)
MatchCountHow many actors were returned. May exceed the number of matched groups — a group usually holds several actors

5. Filter Actors Map by Tag

"A map where the key is an actor and the value is its list of tags. Filter actors by tag."

PinMeaning
ActorMapThe Actor → Tags map itself
TagThe query tag. Checked against each entry's tag list (the value)
bExactMatchAs usual: false — hierarchical, true — exact
OutActorsKey actors whose tag list contains the query
MatchCountHow many were found

General matching rules

  • Entries with empty/invalid actors are silently skipped; an empty query tag → empty result.
  • Hierarchy only works for tags registered in the project's tag dictionary (Project Settings → Gameplay Tags). Custom names outside the dictionary match exactly only.
  • Hierarchy direction is always parent → children: a parent query finds descendants, not the other way around.

Example

Actor array:   Campfire [Damage.Fire]   Bow [Damage]   Door [Door]

Filter Actors by Tag (query: Damage, bExactMatch = false)
   → Campfire, Bow        (MatchCount = 2)

Filter Actors by Tag (query: Damage, bExactMatch = true)
   → Bow                  (MatchCount = 1)

Installation

Copy the GameplayTagFilter folder into <Project>/Plugins/ and restart the editor. The nodes appear in the palette under the Tag Filter category.

Building from source

"<Engine>\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin
  "-Plugin=<Path>\GameplayTagFilter.uplugin" "-Package=<OutDir>"
  -TargetPlatforms=Win64 -NoSubmit

Or as part of a project: copy the plugin into <Project>/Plugins/ and build the project target.

Note: in UE 5.x the module must contain an explicit IMPLEMENT_MODULE(FDefaultModuleImpl, GameplayTagFilter); — UHT does not always generate the boilerplate (already handled in this source).
